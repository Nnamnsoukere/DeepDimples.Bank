# DeepDimples Bank — Preview

This is a front-end preview only. It is not a bank, wallet, exchange, card issuer, or payment processor. All balance figures are sample values. Live market data, real account balances, P2P quotes, AI chat, transfers, withdrawals, and cards are not connected.

## Deploy on Vercel
Import this repository into Vercel as a static site. No build command is required. If asked, select framework preset **Other** and leave build/output settings at defaults unless Vercel asks for a specific root directory.

## Security
Never commit seed phrases, private keys, bank passwords, API secrets, or sensitive financial data. A private repository is not a secure vault. Real wallet transactions should use a supported wallet's signing interface and clearly show network, recipient, amount, fees, and confirmation. P2P rankings need verified quote sources, timestamps, payment methods, order limits, fees and net rates.
